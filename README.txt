GREEN HORIZON CONSULTING — LOCAL WEBSITE PROTOTYPE

Files
- index.html: responsive website with styling and interactive demo form
- green-horizon-logo.jpg: supplied Green Horizon Consulting logo

Run locally
1. Keep index.html and green-horizon-logo.jpg in the same folder.
2. Double-click index.html to open it in a modern browser.
3. Internet access is needed for the optional hero photograph; the rest of the page is local.

Prototype limitations
- The enquiry form is a visual demonstration. It does not send emails or save submissions.
- Prices and service descriptions are based on the supplied business model and should be validated before any real-world use.
- The website is not deployed publicly and does not require paid hosting.
