# Green Horizon Consulting — Website Prototype

## Run it
1. Download and extract `green_horizon_website.zip`.
2. Open `index.html` in a modern browser.
3. Edit `index.html` for content, `styles.css` for visual design, and `script.js` for interactions.

No build tools, paid services, or installation are required.

## What's included
- Responsive landing page for Green Horizon Consulting
- Services and indicative price ranges
- Nature-based solutions showcase with clearly labelled illustrative concepts
- Four-step approach section
- Mobile navigation
- Cursor splash particles in the supplied green/lime palette (vanilla JavaScript adaptation for this static HTML version)
- Demo enquiry form that downloads a local `.txt` draft; it does not transmit or store personal data online

## Splash Cursor source reference
https://reactbits.dev/tools/background-studio?bg=splash-cursor&colors=10b981%2C84cc16%2C286752&rainbow=false

This prototype implements a lightweight canvas effect in vanilla JavaScript so the site remains easy to open and edit locally. It is not the React Bits package/component itself. If you later provide the exact React component source, it can be integrated into a React build.

## Notes
- Pricing is indicative and should be verified before the site is used commercially.
- Project artwork is illustrative; it does not represent measured outcomes or completed client projects.
- The enquiry form is a local prototype, not a production contact system.
- Google Fonts requires an internet connection; the site otherwise loads local files.
